# ADR-0010: Db entities: naming, keys, audit columns and version

- **Status:** Accepted
- **Date:** 2026-10-17
- **Deciders:** Martin

## Context

[ADR-0002](0002-domain-free-of-ef-core.md) keeps EF entities separate from the domain but
said nothing about their names, keys, when a row was written, or two saves overwriting each
other.

## Decision

- An entity is `Db` + the domain type it stores: `DbUser`.
- It derives from `DbImmutableEntity` (written once) or `DbMutableEntity` (changes). Both
  derive from `DbEntity`: `Id` and `CreatedAt`. `DbMutableEntity` adds `UpdatedAt` and
  `Version`.
- `Id` is the domain's UUIDv7, never generated by the database. Time-ordered, so inserts
  append to the primary-key index like a sequence; one key, and foreign keys need no
  translation.
- The single `DbContext` stamps `CreatedAt`, `UpdatedAt` and `Version` (1, then +1) from an
  injected `TimeProvider` in its `SaveChanges` override, applies the key and the concurrency
  token to every entity by convention, and refuses to save a modified immutable row. Mappers
  never set these columns; the domain never sees them.
- `Version` is a concurrency token: a save whose row changed since it was read throws
  `DbUpdateConcurrencyException`.
- Foreign keys are named explicitly.

## Alternatives considered

- **A bigint sequence key with the Guid as a second unique column**: 8 bytes smaller per key,
  but two unique indexes per table, and every foreign key needs the referenced row's bigint,
  which the domain does not know.
- **PostgreSQL `xmin` as the version**: no column, but invisible, PostgreSQL-only, and changed
  by a dump and restore.
- **Audit columns in the domain**: they describe storage, not the business.

## Consequences

- No configuration can forget a key or the token; adding an entity never touches the context.
- `ExecuteUpdate`/`ExecuteDelete` bypass the stamping and the version.
- The version protects a load-and-save within one request. Protecting an edit across requests
  needs the version in the domain and the page, when a use case needs it.
